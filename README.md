# Launcher
Minecraft-лаунчер для Windows x64.
## Установка
Откройте [последний релиз](https://github.com/1Boss-mma/launcher/releases/latest), скачайте файл `Launcher-Setup-…-win-x64.exe` из раздела Assets и запустите его.
## Обновление
Если лаунчер уже установлен, проверьте обновления в приложении.
[Все версии](https://github.com/1Boss-mma/launcher/releases) · [Сообщить о проблеме](https://github.com/1Boss-mma/launcher/issues)
