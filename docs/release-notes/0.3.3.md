## Что изменилось

- Обновления лаунчера загружаются из GitHub Releases. Адрес закреплён в коде.
- Старые тестовые адреса из настроек больше не влияют на проверку обновлений.
- Убрано поле ввода адреса обновлений.
- В установщик добавлена чистая установка: удаление старых файлов приложения с сохранением сборок, миров и настроек.
- Исправлены перепутанные секции «Обновления», «Оформление» и «О программе» в настройках.
- Подключены автоматическая сборка, проверки и публикация файлов релиза.

## Установка

Скачайте **Launcher-Setup-0.3.3-win-x64.exe** и запустите его.

Если старая версия не видит обновление из-за сохранённого тестового адреса, один раз установите 0.3.3 через установщик. Сборки, миры и настройки сохраняются.
