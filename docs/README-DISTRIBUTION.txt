Лаунчер 0.3.1
=============

1. Распакуйте архив в папку без пробелов и без OneDrive, например:
   C:\Games\Launcher

   Не запускайте из Program Files: лаунчеру нужна запись в свою папку
   для автообновления. Права администратора не требуются.

2. Запустите Launcher.exe.
   Если Windows покажет SmartScreen:
   "Подробнее" -> "Выполнить в любом случае".

3. В лаунчере укажите ник (3-16 символов) и при необходимости папку игры.
   По умолчанию: %LOCALAPPDATA%\SamaraLauncher\instances\<id>

4. Нажмите "Играть".
   При первом запуске скачаются недостающие Java 17, Minecraft 1.20.1,
   Forge 47.4.28 и сборка (если настроен pack.toml).
   Нужен интернет и несколько гигабайт свободного места.
   Следующие запуски проверяют только изменившиеся файлы.

Ник оффлайн: пароль не нужен, Microsoft-аккаунт не требуется.
Сервер должен быть настроен с online-mode=false.

Где лежат настройки:
  %APPDATA%\SamaraLauncher\config.json

Где лежат логи:
  %LOCALAPPDATA%\SamaraLauncher\logs

Где лежат бэкапы:
  %LOCALAPPDATA%\SamaraLauncher\backups

Не удаляйте Launcher.Updater.exe: он нужен для автообновления лаунчера.
Не удаляйте tools\packwiz-installer-bootstrap.jar: он нужен для обновления сборки.

Ограничения:
  только Windows 10/11 x64; Minecraft 1.20.1 / Forge 47.4.28;
  нет delta-обновлений, автоматического отката и подписи кода;
  самообновление заменяет только Launcher.exe;
  для обновления сборки нужен доступный pack.toml по HTTP(S).

Если что-то не работает, пришлите последний файл из папки logs
и укажите, что именно вы делали.
